# Staggered Flow Type / Harf geçişi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/staggered-flow-type/).

İstasyon başlığını gecikmeli ve yumuşak hareketle kur.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Metin
- Harf gecikmesi (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Set a title and the delay between animated letters.

Open [the live tool](https://omerbek.github.io/staggered-flow-type/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
